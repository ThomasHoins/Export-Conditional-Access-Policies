# Changelog

All notable changes to this project will be documented in this file.

## [1.0.1] - 2026-10-30

### Changed
- Simplified Graph error output
- Removed the explicit `ResolveNames` switch pattern in favor of always-enabled name resolution
- Reduced verbosity in console output without changing the exported data
- Added script-level version metadata
- Added project documentation and version history

## [1.0.0] - 2026-10-30

### Added
- Initial release of the Conditional Access policy export script
- Pagination support for Microsoft Graph results
- Combined JSON export, individual policy JSON files, CSV overview, and Excel export
- GUID-to-name resolution for users, groups, apps, named locations, and directory roles
